Cómo se ve en gastos

Cambios RG N Aparece cuando un gasto mantiene diferencias abiertas con Rindegastos.
Al abrir el gasto, el detalle muestra valor actual en Expenses, valor detectado en Rindegastos, id de gasto Rindegastos y acciones para aplicar o ignorar.
Cada aplicación automática o manual queda registrada en la auditoría del gasto con valor anterior, valor nuevo, id gasto Rindegastos e id informe Rindegastos.
